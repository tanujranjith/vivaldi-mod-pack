Update 26 — Compact vertical tabs (pinned grid + waterfall groups)
---

A compact vertical-tab layout is now integrated directly into
`VivaldiAir.css` (no extra CSS file). It is scoped **only** to LEFT / RIGHT
vertical tab bars — top/bottom horizontal tabs, panels, workspaces, menus,
the address bar and the start page are untouched, and the Vivaldi Air glass,
blur, rounded corners and custom icons are all preserved.

What you get on a vertical tab bar:

- **Pinned tabs** become favicon-only square tiles in a responsive grid
  (more icons per row as the sidebar widens) — Arc / Zen style.
- **Normal tabs** stay full-width rows below the grid, keeping titles,
  favicons, hover, active styling, audio/mute indicators and a hover-only
  close button.
- **Tab groups** (native Accordion stacks) cascade inline as a vertical
  *waterfall*: child tabs are indented under the coloured group header in the
  same column, with a colour guide rail. The group keeps its colour, name and
  tab-count badge. No second horizontal strip, no empty arrow row.
- **Hibernated tabs** grey out *only* the favicon; the title, group colour,
  count badge and audio stay readable, and the favicon restores on hover / when
  the tab becomes active.

```
[icon][icon][icon][icon]
[icon][icon][icon]

Normal Tab Title
Normal Tab Title
▶ Group Name                 8
    Child Tab Title
    Child Tab Title
Normal Tab Title
+
Trash / Sync controls
```

### Setup

**Required (CSS modifications):**

1. Open `vivaldi://experiments`
2. Enable **"Allow for using CSS modifications"**
3. Open **Settings > Appearance > Custom UI Modifications**
4. Select the folder containing `VivaldiAir.css`
5. **Fully quit and reopen Vivaldi** (Ctrl+R only reloads the page, not the UI shell)

> Keep this as the only `.css` file in that folder. Vivaldi loads *every* CSS
> file in the configured folder, so stacking old/overlapping stylesheets causes
> load-order conflicts. The bundled backup is named `VivaldiAir.original.css.bak`
> precisely so Vivaldi ignores it — to roll back, delete `VivaldiAir.css` and
> rename the backup to `VivaldiAir.css`.

**Required for the waterfall tab groups:**

- **Settings > Tabs > Tab Features > Tab Stacking > Accordion Tab Stacks**
  (Vivaldi's default *Two-Level* mode is what puts a stack's children in a
  separate strip — switch to Accordion for the inline waterfall.)

**Recommended for hibernated-favicon behaviour:**

- **Settings > Tabs > Tab Display > Dim Icon when Hibernated**

### Tuning

All sizing knobs live in the `V0. TUNING` block at the bottom of
`VivaldiAir.css` (`--vpg-*` variables): pinned tile size, pinned favicon size,
pinned tile radius, grid gap, normal row height, normal favicon size, accordion
child-row height, accordion indent, guide-rail thickness and the hibernated
favicon opacity. The tile/row radii default to the modpack's own `--radius`.

### Note on Vivaldi updates

The vertical-tab layout depends on Vivaldi's **internal** UI class names
(`.resize`, `.tab-position.is-pinned`, `.tab.tab-accordion`,
`.tab.tab-in-accordion`, `.tab-position.accordion-toggle-arrow`,
`.stack-counter`, `.tab-position.colored`, `.tab.isdiscarded`). These are not a
public API and may change after a major Vivaldi update — if pinned tiles or the
waterfall stop rendering correctly after an update, these selectors are the
first thing to re-verify. Verified against Vivaldi 8.0.
